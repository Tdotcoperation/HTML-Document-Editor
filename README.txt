HTML 문서 편집기 v2

파일
- index.html
- style.css
- editor.js

주요 변경
1. 브라우저 alert/confirm/prompt를 사용하지 않습니다.
   새 문서, 저장 이름, 링크, 찾기 등은 모두 사이트 안 중앙 팝업으로 표시됩니다.

2. 저장
   저장/Ctrl+S를 누르면 중앙 팝업에서 문서 이름을 입력합니다.
   OK를 누르면 그 이름이 편집기의 문서 이름으로 설정되고 <이름>.html 파일이 다운로드됩니다.

3. 데스크톱/모바일 메뉴
   - PC: 파일/용지 크기 같은 목록형 메뉴는 누른 버튼 바로 아래에 드롭다운으로 표시됩니다.
   - 모바일: 같은 기능은 하단 바텀시트로 표시됩니다.

4. 용지
   A2, A3, A4, A5, A6, ISO B4, ISO B5를 지원합니다.
   세로/가로 방향과 여백을 바꿀 수 있습니다.
   인쇄 시 사이트 UI를 전부 제거하고 문서 용지만 출력합니다.

5. HTML 전용 기능
   - iframe 삽입
   - 비디오 / 오디오 URL 삽입
   - details(접기/펼치기)
   - 코드 블록
   - HTML 원본 편집
   - 독립 HTML 미리보기

6. 그림/iframe 자유 배치
   그림과 iframe은 position:absolute 개체로 문서 글자보다 위(z-index)에 올라갑니다.
   따라서 이동해도 본문 글자 흐름이 바뀌지 않습니다.
   개체를 클릭하면 테두리/크기 조절 핸들이 표시됩니다.
   - 드래그: 이동
   - 네 모서리: 크기 조절
   - ↥/↧: 다른 떠 있는 개체 사이의 앞/뒤 순서
   - ×: 삭제
   iframe은 '조작' 버튼으로 iframe 내부 조작 모드를 켜고 끌 수 있습니다.

7. 글꼴/글자 크기
   Pretendard 기본, Wanted Sans Variable / G마켓 산스 / Paperlogy 고정 바로가기,
   100개 이상의 글꼴 목록, PC에서 1~300pt 자유 입력을 지원합니다.

주의
- file:// 로 직접 열어도 대부분 기능이 동작합니다.
- iframe 대상 사이트가 X-Frame-Options/CSP로 외부 삽입을 막은 경우 해당 사이트는 iframe에 표시되지 않을 수 있습니다.
- 일부 브라우저의 보안 정책 때문에 '붙이기' 버튼은 사이트 내부 붙여넣기 창을 사용합니다. Ctrl/Cmd+V는 편집 영역에서 그대로 사용할 수 있습니다.

8. 자동 페이지 나누기 (v3)
- A2/A3/A4/A5/A6/B4/B5 등 현재 선택한 용지의 실제 높이를 고정합니다.
- 입력 내용이 현재 페이지의 아래쪽 여백을 넘으면 다음 페이지를 자동 생성합니다.
- 긴 한 문단도 글자 단위로 적절한 위치에서 나누어 다음 페이지로 이어집니다.
- 앞 페이지의 내용을 삭제하면 다음 페이지 내용이 가능한 만큼 자동으로 앞으로 당겨집니다.
- 내용이 없어져 필요 없어진 마지막 페이지는 자동 삭제됩니다.
- 수동 '쪽 나누기'는 강제 페이지 경계로 유지됩니다.
- 하단 상태 표시줄에 현재 쪽 / 전체 쪽 수가 표시됩니다.
- 저장되는 HTML에도 여러 페이지가 각각 별도 페이지로 보존되며, 다시 열었을 때 페이지 구조를 복원합니다.
- 인쇄/PDF 출력 시 생성된 모든 페이지를 순서대로 출력하고 사이트 UI는 출력하지 않습니다.


v3.1 Enter 수정
- 일반 Enter는 브라우저 기본 새 문단/새 줄 동작을 그대로 사용합니다.
- 새 빈 문단의 커서 위치를 페이지 재배치 후에도 정확히 보존합니다.
- 페이지가 실제로 넘칠 때만 자동 페이지 분할을 실행합니다.
- Ctrl/Cmd+Enter는 기존처럼 강제 쪽 나누기입니다.


v4.0 오프라인 설치
- 검토 탭 → 맞춤법 표시 옆에 "오프라인 설치" 버튼 추가.
- 설치 마법사: 설치 확인 → 업데이트 안내 → 주의사항 → 다운로드 항목/예상 용량 → 진행률 → 완료.
- 설치 중 표시: 진행률 %, 실제 받은 용량, 현재 받는 파일, 완료 개수, 남은 개수.
- 설치 완료 팝업에 "다운받은 버전"과 "온라인 버전"을 표시.
- 인터넷 연결이 끊기면 상단에 "오프라인 모드" 표시.
- 편집기 본체와 Tossface/핵심 글꼴/웹 글꼴 목록을 Cache Storage에 저장.
- 온라인에서는 최신 네트워크 버전을 우선 사용하고, 오프라인일 때 설치된 캐시로 폴백.
- 온라인 버전이 바뀌어도 기존 오프라인 버전은 자동 갱신하지 않으므로 설치 버튼으로 다시 다운로드해야 함.
- 브라우저 기본 beforeunload 확인창을 제거하여 앱 내부 팝업 원칙을 유지.

중요:
Service Worker는 file://에서 동작하지 않습니다.
실제 오프라인 설치 기능은 HTTPS 배포 주소 또는 localhost/127.0.0.1에서 실행해야 합니다.


v4.0.1 Google Fonts 오프라인 설치 수정
- 모든 글꼴에 wght@400을 강제하던 문제를 수정했습니다.
- Sunflower처럼 400 weight가 없는 글꼴은 300/500/700 등 사용 가능한 weight를 자동 탐색합니다.
- 한 웹폰트가 실패해도 오프라인 설치 전체가 중단되지 않고 해당 글꼴만 건너뜁니다.
- 설치 완료 화면에서 건너뛴 웹폰트가 있으면 목록을 표시합니다.
- 온라인에서 일반 글꼴을 선택할 때도 동일한 자동 weight 탐색을 사용합니다.
- 성공한 글꼴별 Google Fonts CSS 주소를 저장하여 오프라인 선택 시 재사용합니다.
